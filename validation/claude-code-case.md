# 홈 모바일 LCP 7.97초 → 3.84초 개선 (`dev-portfolio`)

- **Skills & Libraries**: Lighthouse 13.5.0 (측정). 사용한 프레임워크·라이브러리는 제공 자료에 기록되어 있지 않습니다.
- **작업 일자**: 2026.09.30
- **대상**: 홈 화면 초기 로딩 (한글 폰트 로딩, 소개 문장 등장 방식, 모달 지연 로드)

- **문제**— 홈 화면을 모바일 Lighthouse로 3회 측정한 결과, 중앙값이 Performance 65점, LCP 7,973.6 ms, FCP 4,059.9 ms였습니다. 폰트 전송량은 501,012 bytes로, 같은 측정의 Script(445,115 bytes)보다 많았습니다. 작업 기록에는 최초 51점이 있었다고 적혀 있으나, 이 측정의 JSON은 남아 있지 않습니다. 그래서 이 문서는 51점이 아니라 JSON이 남아 있는 `baseline` 단계를 변경 전 기준으로 삼았습니다.
- **원인**— 전체 소스 코드와 전체 Lighthouse 보고서가 제공되지 않아 원인을 코드로 확인하지 못했습니다. 측정 자료에서 확인되는 사실은 두 가지입니다. 첫째, 변경 전 전송량 중 폰트 비중이 가장 컸습니다. 둘째, FCP·LCP가 크게 줄어든 단계(`home-font`, `final`)에서 폰트 전송량도 함께 줄었습니다. 따라서 "한글 폰트 전송량이 초기 렌더링을 늦췄다"는 설명은 측정과 일치하는 가설입니다. 다만 확인된 원인은 아닙니다.
- **해결**— 작업 기록에 따르면 한글 폰트 로딩 방식과 소개 문장의 등장 방식을 개선했습니다. 모달 지연 로드도 실험했지만 모달 닫힘 회귀가 발생했습니다. 그래서 지연 로드 범위를 모달 콘텐츠 렌더러로 줄였고, 이 상태(`verified`)를 최종 상태로 채택했습니다. 중간 단계인 `optimized`의 중앙값 88점은 최종 상태의 수치가 아니므로 성과로 쓰지 않았습니다.
- **결과**— `baseline` 대비 `verified` 중앙값 기준으로 Performance가 65점에서 87점(+22점)으로 올랐습니다. LCP는 51.9%, FCP는 59.2% 줄었고, 폰트 전송량은 71.6% 줄었습니다. 반면 TBT는 82.5 ms에서 87.5 ms로 5.0 ms 늘었고, Script 전송량은 0.6%만 줄었습니다. `baseline` 1회차의 FCP(1,205.9 ms)는 `verified`의 세 회차(1,656.3~1,657.7 ms)보다 빨랐으므로, FCP 개선은 중앙값 기준에서만 성립합니다.

## 측정 조건

- **출처**: [`measurements.json`](existing/measurements.json)과 [`notes.md`](existing/notes.md)입니다. 두 파일 모두 2026-09-30 작업 당시 생성된 기존 자료이며, 이 문서를 작성하면서 새로 측정하거나 앱을 실행하지 않았습니다.
- **대상**: 로컬 프로덕션 빌드의 홈 화면입니다(`"Local production home"`). 사용한 서버 주소·포트·빌드 명령은 자료에 없습니다.
- **도구**: Lighthouse 13.5.0, `throttlingMethod: "simulate"`입니다. 실제 브라우저에서 관측한 값이나 실사용자 지표가 아니라 Lighthouse 시뮬레이션 값입니다.
- **모바일 설정**: `formFactor: mobile`, 412×823 @1.75x, RTT 150 ms, 처리량 1,638.4 Kbps, CPU 감속 4배를 적용했습니다. 이 CPU 감속은 특정 저사양 기기를 재현한 것이 아닙니다.
- **캐시**: `disableStorageReset: false`이며 `clearStorageTypes`는 file_systems, shader_cache, service_workers, cache_storage였습니다.
- **반복·집계**: 단계별로 3회씩 순차 실행했습니다. 중앙값은 지표마다 따로 계산한 값이어서, 점수와 각 지표의 중앙값이 같은 회차에서 나온 것은 아닙니다.
- **누적 실험**: 자료에는 단계들이 "sequential cumulative experiments"라고 적혀 있습니다. 하지만 각 단계 이름(`text`, `font`, `modal` 등)이 어떤 코드 변경에 해당하는지는 기록되어 있지 않습니다.
- **원본 보고서 없음**: `measurements.json`은 회차별 Lighthouse JSON(`reports/lighthouse/mobile-performance/*.json`)에서 추출한 값입니다. 원본 보고서 파일은 이 자료에 포함되어 있지 않습니다.
